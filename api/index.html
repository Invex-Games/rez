Invex.Rez

The core templating library.

Invex.Rez.Abstraction

Type Kind Description
IResolver Interface Resolves variables and functions in a Rez template into an output string.
IResolverSource Interface Provides a map of variables and functions to be used by an IResolver.
IResolverStore Interface An IResolverSource that also supports adding and removing variables and functions at any time.
FunctionCall Record struct Contains the raw argument text for a Rez function call.
RezResolutionException Class Thrown when a template cannot be resolved, such as a cycle that exceeds the 4096 depth limit.

Invex.Rez.Configuration

Integration with Microsoft.Extensions.Configuration and dependency injection.

Type Kind Description
ConfigResolverSource Class An IResolverSource that resolves variables from an IConfigurationRoot.
IResolvableConfig Interface An IConfigurationRoot whose values are resolved with an IResolver on read.
Setup Static class Extension methods for registering Rez configuration services with dependency injection (AddResolvableConfiguration).

Typical flow

var resolver = new Resolver()
    .AddSource(new ResolverStore())                                   // runtime overrides
    .AddSource(new ResolverSource(new Dictionary<string, string>      // fixed defaults
    {
        ["env"] = "production"
    }));

var text = resolver.Resolve("Deploying to {env}");
